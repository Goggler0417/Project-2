# Tagmark v2.18

구형 Tagmark UI를 유지하면서 Page별 데이터 Schema와 UI 연결을 분리하는 1차 구현입니다.

## 이번 버전
- 구형 북마크 카드의 고정 구조를 유지하고 제목/URL/정보줄/등장인물/카테고리/태그/메모의 데이터 필드를 연결할 수 있습니다.
- 카드의 등장인물/카테고리/태그/메모 섹션 제목을 Page별로 변경할 수 있습니다.
- 북마크 편집기에서 표시할 필드의 순서와 숨길 필드를 별도로 설정할 수 있습니다.
- 프로필 카드의 제목/그룹/정보 필드 및 그룹·프로필 태그 표시 제목을 설정할 수 있습니다.
- Tag Head 색상을 태그 박스 표시로 자동 연결합니다.
- 데이터 타입과 입력 타입의 호환 제한은 기존 구조를 유지합니다.
- 기존 구형 DB를 읽거나 변환하지 않으며 신형 IndexedDB만 사용합니다.

## 구조
Page / Data / Schema / UI Component를 분리하는 방향의 기반 버전입니다.
