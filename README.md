# v3.09

## 핵심 수정
- v3.08의 심각한 렉 원인이던 재귀적 `MutationObserver` 제거.
- 메인 페이지 → 페이지 진입을 단일 이벤트 컨트롤러로 재연결.
- 왼쪽 남색 페이지 칼럼을 실제 멀티페이지 상태에서 직접 다시 그리도록 수정.
- 페이지 생성 후 칼럼/현재 페이지/탭 상태를 즉시 동기화.
- 동적으로 다시 생성되는 툴바 버튼을 이벤트 위임 방식으로 연결하여 렌더 후 버튼이 죽는 문제 보완.
- 페이지 설정의 탭 추가 기능도 동일 컨트롤러에서 처리.

## 구조 원칙
- 메인 페이지 → 페이지 → 탭 계층 유지.
- 탭 추가는 페이지 설정에 위치.
- 탭 설정/필드 설정/북마크 추가/태그 머리 수정은 각 탭 툴바에 위치.

## 검수
- 전체 인라인 JavaScript 구문 검사 통과.
- v3.08의 무한 DOM 재렌더 원인 제거 확인.
