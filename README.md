# Tagmark v2.01

신형 Main Page → Page → Tab 구조를 기반으로 구형 Tagmark의 로컬 기능을 새 코드로 재구현한 버전입니다.

- Supabase/로그인/클라우드 동기화 제거
- 기존 Tagmark IndexedDB(`tagmark-local-v1`) 데이터 구조와 호환
- 최상위 category를 Page로 사용
- Page별 Tab 및 기능 ON/OFF
- Main Page Grid/List, A→Z/Z→A
- 북마크, 태그/태그 머리, 프로필, 캐릭터, Folder, 검색/정렬, 일괄 작업, 백업/가져오기
- 버전: v2.01
