# Bookmark Database Editor v1.4

## 이번 버전
구형 최신 모델의 UI와 기존 기능을 기반으로 신형 개발을 다시 구성한 버전입니다. 기존 구형의 실제 화면/동작을 유지하면서 Page별 기능 모듈 ON/OFF를 추가했습니다.

### 보존된 구형 기능
- 카테고리 관리 및 상위/하위 카테고리 구조
- 메인 북마크 목록, 검색, 검색 범위, 정렬 및 오름/내림차순
- 북마크 추가/수정/복제
- URL, Title, Category, Artist, Series, Tag, Page/Duration, Note
- Character/Cast 등록 및 복사/일괄 처리
- 태그 필터와 태그 포함/제외 순환 필터
- 사전등록 태그와 태그 카테고리 표시 설정
- 프로필 등록/수정 및 Character/Cast 프로필
- 북마크 폴더 생성/수정/삭제 및 폴더 일괄 작업
- 백업/가져오기
- Supabase 로그인/닉네임/클라우드 업로드/다운로드/실시간 동기화

### Page별 기능 모듈
페이지(구형의 최상위 카테고리)를 선택한 뒤 상단의 `페이지 기능`에서 기능을 개별적으로 켜고 끌 수 있습니다.
- 북마크
- 태그
- 프로필
- 카테고리
- 등장인물
- 프로필↔등장인물 연결
- 클라우드 동기화

기능을 끄더라도 해당 데이터는 삭제하지 않습니다.

## 주의
이번 버전은 구형 최신 모델을 기준으로 기능 보존을 우선했습니다. 이후 버전에서 이 기능들을 신형의 명시적인 `Main Page → Page → Tab` 구조로 내부적으로 정리하면서, 각 모듈을 더 세밀하게 독립시킬 수 있습니다.
