# Tagmark v2.17

구형 Tagmark UI를 기본 컴포넌트로 유지하면서 Page별 데이터 필드 연결과 표시 규칙을 설정할 수 있도록 구조를 확장한 버전입니다.

## 주요 변경
- 구형 북마크 카드 구조를 기본 Bookmark Card 컴포넌트로 유지
- Page별 UI 연결 설정 추가: 제목/URL/정보줄/등장인물/카테고리/태그/메모
- 프로필 카드도 제목/그룹/표시 필드를 별도로 연결
- Profile Tag는 기본적으로 프로필 카드에 중복 표시하지 않음
- Tag Head 색상을 태그 박스 스타일에 자동 적용할 수 있음
- Bookmark/Profile 기본 시스템 필드는 새 Page 생성 시 기본 제공되며 UI 설정에서 어느 위치에 연결할지 변경 가능
- 데이터 타입과 입력 타입의 호환성은 기존 v2.16 규칙 유지
- 실제 데이터와 UI 설정을 Page 내부에서 분리

## DB
기존 구형 IndexedDB를 읽거나 변환하지 않습니다. v2.17 전용 신형 Schema DB를 사용합니다.
