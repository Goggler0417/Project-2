# Tagmark v3.07

## 구성
- `index.html` — Tagmark v3.07 실행 파일
- `README.md` — 버전 설명 및 변경사항

## v3.07 변경사항
- 페이지 추가 기능 재연결 및 수정
- 툴바 UI를 기존 Tagmark 구형/신형 계열에 가깝게 정리
- 검색, 정렬, 보기 방식, 탭 설정, 필드 설정, 항목 추가 기능을 탭 툴바 영역으로 정리
- 탭 추가 기능을 탭 설정에서 제거
- 탭 생성/삭제/순서 등 구조 관리를 페이지 설정으로 이동
- 탭 설정은 현재 탭 자체의 설정을 담당하도록 역할 분리

## 구조 원칙
Tagmark 신형은 `메인 페이지 → 페이지 → 탭` 구조를 유지합니다.

- 메인 페이지: 페이지 목록 및 최상위 진입점
- 페이지 설정: 페이지 및 하위 탭 구조 관리
- 탭 설정: 현재 탭의 설정 관리
- 툴바: 현재 탭의 검색, 정렬, 보기, 추가, 편집 기능 영역

`index.html`을 브라우저에서 엽니다.
