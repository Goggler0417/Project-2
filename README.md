# Tagmark v2.37

- Character 입력을 고정 UI가 아니라 Field 내부의 독립 Schema로 변경.
- Bookmark/Profile 탭에서 Character Field를 추가한 뒤 내부 Field를 직접 추가/삭제/이름 변경 가능.
- 내부 Field 입력 방식: 이름/Profile/Tag, 성별, Tag 검색, Text, Long Text, Dropdown, Checkbox.
- 각 Character Tag 입력 Field마다 허용 Tag Head를 체크박스로 별도 지정.
- Profile 탭의 Character Field 구성은 해당 Profile Tab Schema에 독립 저장.
- Field Editor의 행 Grid/정렬/폭을 다시 정리하고 작은 화면 대응.
- 새 Tag 추가를 Tag Head 복수 체크 + 태그 내용 다중 입력 방식으로 변경. 선택된 각 Tag Head에 자동 생성.
