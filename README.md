# Tagmark v2.15

신형 Schema DB를 유지하면서 태그/프로필 연결과 검색 입력을 개선한 버전입니다.

- 각 탭 설정에서 사용할 태그 머리를 선택할 수 있음
- 필드에서 별도 태그 머리 제한을 지정하면 해당 필드 설정이 탭 설정보다 우선함
- 태그 검색 입력에서 탭/필드의 태그 머리 범위를 적용
- 프로필 검색/프로필 추가 입력은 프로필의 이름으로 생성된 프로필 태그를 검색하고, 선택 시 실제 연결된 Profile ID를 저장
- 프로필 추가 입력에서는 연결된 Profile의 정보를 함께 표시
- 프로필 제목으로 생성되는 프로필 태그는 일반 Tag 데이터로 저장되어 Tag 탭에서 조회 가능
- 프로필 태그는 Tag 탭에서 수정/삭제할 수 없으며 이름은 Profile 제목과 동기화됨
- 프로필 탭 설정에서 프로필 태그에 자동으로 지정할 Tag Head를 선택할 수 있음
- 프로필 카드에서는 프로필 태그를 별도 표시하지 않음
- 기존 Page/Tab/Schema/DB 구조와 기존 로컬 신형 DB를 유지하며 구형 DB를 읽거나 변환하지 않음
