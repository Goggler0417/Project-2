# Tagmark v2.13

신형 Schema DB 구조를 유지하면서 구형 Tagmark의 실제 시각 규격을 기능 단위로 적용한 버전입니다.

- 북마크 카드: 구형의 폰트, 크기, 간격, 정보 배치, 선택 체크박스, 수정/복제/삭제 버튼 위치 적용
- 폴더: 구형의 접이식 폴더 헤더/본문 구조 적용
- 프로필: 구형 프로필 폴더/카드/버튼 배치와 타이포그래피 적용
- 태그: 구형의 분류형 접이식 목록과 우측 수정/삭제 버튼 배치 적용
- 카테고리: 구형 목록형 분류 UI에 맞춘 스타일 적용
- 신형 Page/Tab/Schema/DB 구조는 그대로 유지
