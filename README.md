# v3.10

신형 범용 데이터베이스 계열의 구조 정리 버전.

## 기준 구조
- Main → Page → Tab 계층을 고정 구조로 사용합니다.
- 왼쪽 남색 칼럼은 실제 Page 목록을 DB 상태에서 직접 렌더링합니다.
- Page 생성/전환 시 전체 화면을 단일 render 흐름으로 갱신합니다.
- 탭 관련 실행 기능은 각 탭의 툴바에 배치합니다.
- 탭 추가/구조 관리는 페이지 설정에서 수행합니다.

## 이번 재작성
- v3.05 이후 덧붙였던 별도 patch/controller 레이어를 사용하지 않고 신형 원본 구조에서 단일 controller로 재구성했습니다.
- 툴바를 검색/정렬/보기/선택/탭 설정/필드 설정/추가 기능의 한 영역으로 통일했습니다.
- 페이지 설정 안에 탭 관리 및 탭 추가를 배치했습니다.
- 브라우저 confirm/prompt/alert를 제거하고 앱 내부 modal로 통일했습니다.
- 선택 북마크 삭제 및 폴더 지정/제외/새 폴더 생성 후 추가를 제공합니다.
- 폴더 삭제 시 북마크 자체는 삭제하지 않고 폴더 참조만 제거합니다.
- HTML 표시 버전과 백업 파일 버전을 v3.10으로 통일했습니다.

## 검증
- JavaScript 구문 검사 통과.
- HTML inline 이벤트 핸들러 59종을 정적 검사하여 정의되지 않은 함수 참조 0건 확인.
- 시스템 confirm/prompt/alert 호출 0건 확인.
- 과거 v2.04/v3.05/v3.08/v3.09 버전 문자열이 실행 HTML에 남지 않았음을 확인.

주의: 현재 실행 환경의 headless Chromium이 종료되지 않는 문제 때문에 실제 Chromium 자동 클릭 테스트는 완료하지 못했습니다. 따라서 실제 브라우저 클릭 검증을 했다고 표기하지 않습니다.
