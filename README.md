# Tagmark v2.09

신형 Schema DB 기반의 Bookmark Database Editor.

## 이번 버전

- 등장인물 필드/입력 방식 추가
  - 한 필드 안에서 여러 등장인물을 자유롭게 추가·삭제
  - 등장인물별 이름을 직접 텍스트로 입력
  - 기존 프로필 태그 검색 및 연결
  - 프로필 태그 선택 시 연결된 Profile 정보와 프로필 태그를 함께 연결
  - 등장인물별 성별과 character/cast 구분
  - 등장인물별 추가 태그 검색·추가·삭제
  - 선택 / 선택 해제 / 선택 삭제 / 복사 / 붙여넣기
- Profile 제목으로 생성되는 Profile Tag는 일반 Tag 데이터로 유지하고 `profileId`로 Profile과 연결
- Tag 검색 입력칸에서 검색 중 새 Tag를 즉시 생성 가능
- Profile / Category / Folder 검색 입력 방식도 실제 검색형 입력 UI로 변경
- 숫자 / 날짜 / 날짜시간 / 기간 / URL / 색상 / 평점 입력 방식 보강
- 필드 편집 UI 재구성
- 필드 설정 팝업 저장 시 부모 필드 편집 내용이 사라지는 문제 수정
- 필드 선택지 및 태그 머리 설정을 임시 Schema Draft에 저장한 뒤 최종 저장하도록 변경
- 필드 순서는 드래그로 변경
- Folder 삭제 시 Bookmark와 Profile 양쪽의 연결도 정리
- Page/Tab 제목 앞의 아이콘을 사용하지 않음
- Page에는 기본 사용자 필드를 자동 생성하지 않음

## 데이터 원칙

구형 DB를 읽거나 변환하지 않습니다. 구형은 기능/UI 참고 자료로만 사용하며, 신형 로컬 IndexedDB 구조를 사용합니다.

현재 버전은 기존 신형 DB 저장 공간을 계속 사용하여 이전 신형 데이터와의 연속성을 유지합니다.
